# 应急周报

公开信息整理与研判参考。首页展示最新一期，历史目录保留往期，手机与电脑均可阅读。

每条新闻按完整区块使用浅灰、白色交替底色；新闻内事实使用普通字体，研判、建议及适用边界使用整段括号与斜体，不使用彩色段落卡片。每期独立二维码位于`public/qrcodes/年份-期号.png`，指向对应期刊的永久阅读地址。首页与期刊页面提供图片下载，新一期发布后旧二维码仍指向原期刊。

05为来源与资料，06为默认折叠的下周建议办理清单。从第二期起逐项回应上期清单，区分核验进展、待核实和后续安排，保留原建议的回看链接。

本仓库仅包含拟公开的网站内容与发布程序。新闻事实请查阅每期来源，研判与建议不代表机关正式签发文件。

## 审核与发布

制作、原始资料归档和审核在本地进行。用户确认具体期刊后，操作者将该版本同步到本仓库，再启动 Publish reviewed weekly report 工作流。

工作流只允许手动触发，不会因普通提交而自动公开新版本。触发时传入经审核的 public 目录摘要；构建会核对摘要与当前文件是否一致，避免审核后修改的版本直接上线。此摘要校验是版本核对措施，不能代替人工内容审核。

首次在仓库 Settings → Pages 中设置 Source 为 GitHub Actions。无需购买域名，使用 GitHub Pages 默认网址。免费方案使用公开仓库，因此仅可上传拟公开内容。

大陆和微信访问需部署后实测，托管成功本身不能证明所有地区都能访问。

## 本地检查

`python build_pages.py --print-digest` 输出公开内容摘要。

`python build_pages.py --base-path /emergency-weekly` 检查项目路径发布时的站内链接。首页、目录、期刊、附件使用同一目录结构，CSS、脚本及字体不依赖第三方 CDN。
